## 2. B 方案数据流（一次声明制运行）

```text
git 仓库 ──probeHost──▶ host-preflight ─┐
              ──detectCProject──▶ project-detection ─┤──注入 AI 会话
                                                     │
        ┌─── analyze(host 探针，零模型) ──▶ 分析 artifact ──┤
        │                                                  ▼
Claude │                          WORKFLOW_GENERATION
        │              test-writer 主会话（workflow-session.ts 编排）
        │               │ inspectWorkflow 查库
        │               │ 派 build-writer ──generateBuildWorkflow──▶ runs/{session}/workflows/build/*.ts
        │               │ declareDependency(最终依赖集)
        │               └─ Write test workflow（限自己的文件）
        │                                                  ▼
        └─── runRefactor ──▶ candidate commit ──▶ patch-record
                                                           │
                            DeclaredBuildSet（声明集凭证）提交状态机
                                                           │
                      ┌────────────────────┴──────────────────────┐
                      ▼  对声明集里每个 build 循环执行（空集跳过）    ▼
              baseline worktree                            candidate worktree
              逐个 executeBuildWorkflow                    逐个 executeBuildWorkflow
              executeTestWorkflow                          executeTestWorkflow
                      │                                            │
                  期望/CTest 基线                              期望/CTest 候选
                      └────────────────────┬──────────────────────┘
                                           ▼
                             compareExpectations / compareCTestSuites
                                           ▼
                          状态机：consistent → ACCEPTED / inconsistent → REJECTED
                                           ▼
                          curator：判定入库 → 稳定 id + alias.json
```

## 3. 磁盘上的工作区

| 目录 | 谁写 | 内容 |
|---|---|---|
| `.refactor/sessions/<id>/` | SessionStore / session-store.ts | state.json、artifacts/*.json、worktrees/（用完删） |
| `runs/{sessionId}/workflows/` | dep-registry（B 方案新增） | 本次会话 AI 生成的 build/test workflow 源码 |
| `.refactorsa/` | registry + curator | 跨会话注册表（源码+manifest+hash+description）+ alias.json |
| `<root>/<run-id>/` | E2ELogger（log.ts） | state.json、run.jsonl、artifacts/、logs/（Dashboard 读这里） |
