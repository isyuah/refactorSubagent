# text_copy 体验项目

这是一个很小的 C 库，只有 `text_copy` 一个公开函数，没有现成的测试和可执行程序。
现有 CMake 流程只生成静态库；可以编写独立辅助程序，链接真实实现并观察其行为。

函数契约写在 `include/text_copy.h`。返回值包含状态、实际复制长度和原字符串长度。
需要关注正常复制、恰好容纳、截断、容量 0/1、空字符串、NULL 参数、终止符和缓冲区边界。
源字符串必须以 NUL 结尾，源与目标不得重叠；无需测试违反这两个前提的输入。

可尝试的重构需求：合并完整复制与截断复制中的重复循环，保持公开接口、状态、长度、
终止符、无效输入时不写入的行为和缓冲区外字节完全不变。
